# One Word for the Boss

Entry for the make.fun competition [One Word for the Boss](https://make.fun/c/u-swift-badger-44-one-word-for-the-boss-6b48c735): exactly one word describing the boss — **Lurker**.

## Run

```sh
node main.ts
```

Writes `Lurker` (6 characters) to `$ENTRY_OUTPUT` or `/output/entry.txt`.
